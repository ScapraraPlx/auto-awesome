# auto-awesome
This is the demo test automation framework, which was built just to demonstrate the codding skills

# To run the tests, please execute following command: 
```
mvn clean test
````

# To generate test report, please use following command: 
```
mvn serenity:aggregate
````

# Once the report is generated, you'll be able to find it by the following folder: 
```
/target/site/serenity/index.html
````
